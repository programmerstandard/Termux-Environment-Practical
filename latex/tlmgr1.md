# tlmgr
tlmgr is TeX Live's built-in package manager.

## List All Installed TeX Live's Packages

```bash
tlmgr info --only-installed
```

## List All Installed TeX Live's Schemes

```bash
tlmgr info schemes --only-installed
```

## List All Installed TeX Live's Collections

```bash
tlmgr info collections --only-installed
```
