# Check LaTeX Package

## List All Installed LaTeX Package 

```bash
tlmgr info --only-installed
```

## Search LaTeX Package

```bash
tlmgr search <package_name>
```

**Example**

```bash
tlmgr search amsmath
```

## Check Info About A LaTeX Package

```bash
tlmgr info <package_name>
```

**Example**

```bash
tlmgr info amsmath
```
