
## Show Memory Usage

```bash
free -h
```

## Show Overall Disk Space

```bash
df -h
```

## Show Specific Directory Usage

**Example**

In this example will show Hime Directory Disk Usage

```bash
du -sh ~
```

## List Top 10 Largest Files Or Directories 

```bash
du -ah ~ | sort -hr | head -n 10
```
