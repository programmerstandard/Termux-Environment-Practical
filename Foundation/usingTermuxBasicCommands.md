
## Wipes The Terminal Screen To Be Clean

```bash
clear
```

## Display The Current Username 

```bash
whoami
```

## Display The Operating System ( The Actual Device )

```bash
uname -o
```

## Clear Shell Command Cache

```bash
hash -r
```

## Found Command Path Location

```bash
type -a <command-name>
```

## Exit From A Session

```bash
exit
```
