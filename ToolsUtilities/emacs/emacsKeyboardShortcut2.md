# emacs Keyboard Shortcuts 2

Use Termux's On Screen Extra Keys Row as substitute for Ctrl and Alt/Meta.

* Ctrl represented as C+
* Alt or Esc represented as M+

## General Keyboard Shortcuts 

| Action | Shortcut |
|---|---|
| Cancel A Command | C-g |
| Execute An Extended Command | M-x |
| Move Cursor backward one character (backward-char) | C-b |
| Move Cursor forward one character (forward-char) | C-f |
| Search Backward | C-r |
| Search Forward | C-s |

## Prefix C-x group 1

| Action | Shortcut |
|---|---|
| Close Current File / Buffer. | C-x k |
| Maximize Current Window (Delete Other Windows) | C-x 1 |
| Undo/Redo | C-x u |

## Prefix C-x group 2

| Action | Shortcut |
|---|---|
| Exit Application | C-x C-c |
| Open / Create File | C-x C-f |
| Open Dired / list-directory | C-x C-d |
| Save As File | C-x C-w |
| Save File | C-x C-s |
| Toggle Read-Only File | C-x C-q |
