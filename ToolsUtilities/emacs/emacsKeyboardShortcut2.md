# emacs Keyboard Shortcuts 2

Use Termux's On Screen Extra Keys Row as substitute for Ctrl and Alt/Meta.

* Ctrl represented as C+
* Alt or Esc represented as M+


| Action | Shortcut |
|---|---|
| Save File | C-x C-s |
| Open / Create File | C-x C-f |
| Close Current File / Buffer. | C-x k |
| Exit Application | C-x C-c |
| Cancel A Command | C-g |
