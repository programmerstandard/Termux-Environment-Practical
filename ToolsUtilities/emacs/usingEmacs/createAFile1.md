# Create A File In Emacs

in the same folder.

To learn about Install emacs, click [/ToolsUtilities/emacs/emacsSetup.md](/ToolsUtilities/emacs/emacsSetup.md)

## Running emacs

```bash
emacs -nw
```

## Call Create A File Command

```
C-x C-f
```

## Type Your File Name 

* Type your file name with file extension,
* then press Enter.
