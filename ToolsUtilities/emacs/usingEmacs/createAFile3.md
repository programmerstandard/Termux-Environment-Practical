# Create A File 3 ( Using dired )

Dired (Directory Editor) is Emacs’ built-in file manager.

To learn about Install emacs, click [/ToolsUtilities/emacs/emacsSetup.md](/ToolsUtilities/emacs/emacsSetup.md)

## Running emacs

```bash
emacs -nw
```

## Open dired

```
C-x d
```

## Open Folder In dired

1. If cursor on the target folder, 
2. tap Enter.

## Create A File

```
C-x C-f
then type File name with extension file
```

## Switch To shell Buffer

```
C-x b
press Enter
```

## Close The Buffer

```
C-x k
```
