# Essential Emacs Commands & Shortcuts

| Category | Action | Shortcut |
|---|---|---|
| File Management | Save File / Buffer | C-x C-s |
| | Open / Create File | C-x C-f |
| | Toggle Read Only | C-x C-q |
| | Close Current File / Buffer. | C-x k |
| | Exit Application | C-x C-c |
| Command | Execute emacs Extended Command | M-x |
| | Cancel Command | C-g |
| Editing | Undo/Redo | C-x u |
| | Set Mark And Finish Set Mark | C-SPC |

## Notes

* C- is Control ( Ctl ).
* M- is Alternate ( Alt ).
* SPC is Space bar key.
* Use Termux's On Screen Extra Keys Row as substitute for Ctrl and Alt/Meta.
