# Essential Emacs Commands & Shortcuts

| Category | Action | Shortcut |
|---|---|---|
| File Management | Save File | C-x C-s |
| | Open / Create File | C-x C-f |
| | Close Current File / Buffer. | C-x k
| | Exit Application | C-x C-c |
| Navigation | Cancel Command | C-g |

## Notes

* C- is Control ( Ctl ).
* M- is Alternate ( Alt ).
