# Filter The Package By Package Menu

## 1. Open emacs

```bash
emacs -nw
```

## 2. Open A Run emacs Command Mini Buffer

```
Press M-x (Meta or Alt)
```

## 3. Run list-packages Command

```
Type `list-packages` and press `Enter`.
```

## 4. To Switch To Other Buffer

```
Press C-x b
```

## 5. To Close The list-packages Mini Buffer

```
Press C-x k
```

# To Display emacs Only Installed Packages:

## 1. Open emacs

```bash
emacs -nw
```

## 2. Open A Run emacs Command Mini Buffer

```
Press M-x (Meta or Alt), then
```

## 3. Run emacs Only Installed Packages

```
Type `package-menu-filter-by-status`.
```

## 4. Type installed Status

```
Type installed.
```

# To Display emacs Only Available Packages:

## 1. Open emacs

```bash
emacs -nw
```

## 2. Open A Run emacs Command Mini Buffer

```
Press M-x then.
```

## 3. Run emacs Only Installed Packages

