
# cUrl Setup

## Install curl Package

```bash
pkg install curl
```

## Verify curl Installed 

```bash
curl --version 
```

## Fetching A Web Page Content

```bash
curl http://www.example.com
```

## Save As File Name

```bash
cUrl -o myfile.zip http://www.example.com
```

## Check Website Server Status 

```bash
curl -I https://www.google.com/
```
