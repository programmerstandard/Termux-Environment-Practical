

## Essential Vim Commands & Shortcuts
| Category | Action | Shortcut / Command |
|---|---|---|
| Modes | Switch to Insert Mode (start typing) | i |
|  | Return to Normal Mode | Esc |
| File Management | Save file | :w + Enter |
|  | Save and Quit | :wq or ZZ |
|  | Quit without saving | :q! |
| Editing | Undo last action | u |
|  | Redo last action | Ctrl + r |
| Search & Find | Find text | /pattern |
