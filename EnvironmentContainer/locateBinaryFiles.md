
## List All Installed Binary Executables In Your Environment

```bash
ls /data/data/com.termux/files/usr/bin
```

## Identifies Whether A Command Is A Binary File :

```bash
type <command-name>
```

## Locate A Binary, Source, And Manual Page Files For A Command

```
whereis <command-name>
```

## Install Package Which

```bash
pkg install which
```

## Locate Executable Path Of Any Installed Command 

```bash
which <command_name>
```

### Example

```
which node
```
